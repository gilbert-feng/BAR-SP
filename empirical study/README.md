
Codes for procuding the empirical analysis in **Shrinkage estimation and inference for network-linked data: a robust spectral embedding approach**.

The folder `functions` includes the codes to implement the methods.

The folder `data` includes the collected statistical citation network dataset.

The folder `results` includes the estimation results.

The file `APP_stat.R` includes the codes to produce the empirical analysis.

The file `disturb agg.csv` aggregates the results of disturbation experiments from different methods in the empirical analysis.

The file `APP_analysis.R` reproduce the figures in the paper based on the results of empirical analysis.
